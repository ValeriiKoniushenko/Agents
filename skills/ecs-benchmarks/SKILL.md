# ECS Benchmarks

Read the host repository's `AGENTS.md` before using this skill. It defines the ECS
benchmark target, executable, configuration, harness options, coverage expectations, and
any code-generation prerequisites.

Use the documented performance-oriented configuration. Discover the registered benchmark
names before selecting focused runs, keep setup outside the measured region, and use
repeated runs for comparison-quality results. Report the command, configuration, relevant
filters, and measured values so results can be reproduced.
